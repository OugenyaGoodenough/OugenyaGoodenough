# 套磁工具包 / 套磁（事前コンタクト）ツールキット

## 一、研究计划书（研究計画書）骨架

```
1. 研究テーマ（一句话，含手法与对象）
   例：中日言語間の低資源機械翻訳における LLM ファインチューニング手法の検討
2. 背景と問題意識（为什么重要，3-4 段）
3. 関連研究（引用 5-8 篇，必须包含志望教授的近 3 年论文）
4. 研究目的・仮説
5. 研究手法（具体到数据集、基线模型、评价指标）
6. 期待される成果と波及効果
7. 研究計画（修士 2 年的甘特图式安排）
8. 参考文献
```

关键规则：
- 篇幅 1,500-2,000 字（日文），除非募集要项另有规定；
- 「研究手法」必须写到可执行粒度（用什么数据集、什么基线），这是与泛泛申请者的分水岭；
- 引用志望教授论文时要点出「你的研究如何延续/补充其工作」。

```
件名：修士課程進学希望のご相談（南京航空航天大学・北海道情報大学ダブルディグリー ○○）

○○先生

はじめまして。南京航空航天大学と北海道情報大学のダブルディグリープログラムで
日本語学と人工知能を専攻しております ○○ と申します。

現在、北海道情報大学の ○○ ゼミにて「（卒業研究テーマ）」に取り組んでおり、
貴研究室の ○○（論文タイトル、年）を拝読し、特に △△ の手法に強い関心を持ちました。

私の卒業研究では □□ を対象に ◇◇ を行い、（一句具体的な結果：例・BLEU を 2.3 改善）。
その成果は GitHub に公開しております（URL）。

つきましては、20XX 年度修士課程の受験を検討しており、
研究室見学・オンライン面談の機会を頂けますと幸いです。
研究計画書（ドラフト）・成績証明書・履歴書を添付いたします。

お忙しいところ恐縮ですが、何卒よろしくお願いいたします。
```

要点：首封邮件 ≤ 300 字正文 + 附件；不写明理由的广撒网邮件识别度极高，一律避免。

## 三、实验室调研清单（チェックリスト）

对每个目标研究室记录：
- [ ] 教授近 3 年论文 3 篇以上已读并做笔记
- [ ] 研究室的所属学会（言語処理学会 / 人工知能学会 / ACL 系）
- [ ] 中国学生/留学生的在籍情况（从研究室网页、论文作者单位判断）
- [ ] 修士入试方式：一般入试 / 外国人特别选考 / 推荐入试
- [ ] 募集要项中对研究计划书、语言成绩（JLPT/TOEFL）的硬性要求
- [ ] 教授是否接受事前见学
